## Execução da Lista 02

Para executar os exercícios de Pandas no Google Colab:

1. Acesse o notebook da Lista 02 pelo link acima.
2. Adicione a pasta `PANDAS_DADOS` ao ambiente do Colab.
3. Dentro dela, mantenha os arquivos `vendas.xlsx` e `lojas.xlsx`.
4. Execute as células do notebook na ordem indicada.

Os exercícios de NumPy, SciPy e Matplotlib não dependem da pasta `PANDAS_DADOS`, mas precisam das bibliotecas instaladas no ambiente.
